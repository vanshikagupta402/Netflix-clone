# 🎬 Netflix Clone

A Netflix-inspired front-end landing page created with HTML5 and CSS3.

## ✨ Features
- Netflix-inspired dark theme and red branding
- Navigation bar with Home, TV Shows, and Movies links
- Hero section with Play and More Info buttons
- Trending movies and popular shows
- Hover effects and horizontal scrolling
- Responsive design for smaller screens

## 🛠️ Built With
- HTML5
- CSS3

## 📁 Project Structure
```text
Netflix-Clone/
├── index.html
├── style.css
├── README.md
└── Movie image files (.jfif)
```

## 🚀 How to Run
1. Open the project folder in VS Code.
2. Ensure `index.html`, `style.css`, and all referenced image files are present.
3. Install the Live Server extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

## 🖼️ Troubleshooting Images
- Check that the image files are in the correct folder.
- Ensure filenames and extensions match the HTML `src` paths exactly.
- Refresh the browser after saving changes.

## ⚠️ Limitations
This is a front-end practice project. The buttons do not connect to a real streaming service, and there is no backend or video playback.
